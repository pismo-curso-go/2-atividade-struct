# Atividade com Structs em Go

Este projeto foi desenvolvido como parte de uma tarefa do curso de Go.  
O objetivo principal é praticar o uso de **structs**, abordando conceitos como:

- Declaração de structs
- Atribuição de valores
- Manipulação de dados estruturados
- Boas práticas com structs em Go

## 📁 Arquivo principal

- `main.go`: contém a implementação da atividade.

## Como executar

Para rodar o projeto:

```bash
go run main.go
